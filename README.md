# Mundo Mimo — v0.1

Primer prototipo funcional de una app educativa para niños de 0 a 6 años.

## Incluido
- Inicio infantil visual con personajes y botones grandes.
- Juego de parejas funcional.
- Juego de animales y sonidos (voz/sonido real se añadirá con assets).
- Juego de reconocimiento de colores.
- Tres juegos preparados para ampliar: formas, contar y puzles.
- Puerta parental básica.
- Principio de diseño: sin anuncios, sin enlaces externos y sin patrones de recompensa agresivos.

## Ejecutar
1. Instala Node.js.
2. En la carpeta del proyecto: `npm install`
3. Ejecuta `npx expo start`
4. Abre con Expo Go o simulador.
