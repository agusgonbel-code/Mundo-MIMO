# Mundo Mimo — Audio provenance

Launch audit date: 2026-08-19.

Production runtime serves these files from the Mundo Mimo origin. The deployment workflow downloads the referenced source files during build so the child-facing app does not contact Wikimedia at runtime.

## Release requirement

Before App Store / Google Play commercial release, legal/content review must verify the license page for every exact source file and preserve any attribution required by that file's license. The long-term production target is a first-party recorded voice pack for Mimo, Lío and Pipa under a signed commercial voice agreement, replacing mixed public pronunciation clips.
